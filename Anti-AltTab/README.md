# Anti-AltTab Helper

Утилита для предотвращения случайного переключения на другие приложения во время игры через Alt+Tab.

## Возможности

- ✅ **Блокировка Alt+Tab** во время игры
- ✅ **Три режима "жестокости":**
  - `INPUT_BLOCK` - блокирует Alt+Tab
  - `BLACK_SCREEN` - показывает черный экран при попытке переключения
  - `REFOCUS` - возвращает фокус на игру
- ✅ **Safety Key** - горячая клавиша для вкл/выкл защиты
- ✅ **Список запрещенных приложений** - определенные программы блокируются автоматически
- ✅ **Настраиваемая конфигурация** через JSON файл

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что вы запускаете скрипт с правами администратора (требуется для блокировки клавиш)

## Использование

### Базовый запуск

```bash
python main.py
```

### Конфигурация

Отредактируйте `config.json` перед запуском:

```json
{
  "games": [
    "dota2.exe",
    "cs2.exe",
    "LeagueofLegends.exe"
  ],
  "forbidden_apps": [
    "Discord.exe",
    "chrome.exe",
    "Telegram.exe"
  ],
  "cruelty_mode": "INPUT_BLOCK",
  "safety_key": "ctrl+alt+f12"
}
```

**Параметры:**
- `games` - список процессов игр для мониторинга (найдите имя процесса в Диспетчере задач)
- `forbidden_apps` - приложения, которые будут блокироваться во время игры
- `cruelty_mode` - режим блокировки:
  - `INPUT_BLOCK` - блокирует только Alt+Tab (рекомендуется)
  - `BLACK_SCREEN` - показывает черный экран
  - `REFOCUS` - возвращает фокус на игру
- `safety_key` - горячая клавиша для отключения защиты

### Управление

- **Включение/выключение:** Нажмите `Ctrl+Alt+F12` (или вашу настроенную safety key)
- **Остановка:** `Ctrl+C` в консоли

## Режимы работы

### INPUT_BLOCK (Рекомендуется)
Блокирует комбинацию Alt+Tab, но Alt и Tab работают по отдельности. Наименее навязчивый режим.

### BLACK_SCREEN
Показывает полноэкранный черный оверлей с надписью "ФОКУС НА ИГРЕ!" при попытке переключения.

### REFOCUS
Автоматически возвращает фокус на окно игры при обнаружении запрещенного приложения.

## Примеры использования

### Для Dota 2
```json
{
  "games": ["dota2.exe"],
  "forbidden_apps": ["Discord.exe", "chrome.exe"],
  "cruelty_mode": "INPUT_BLOCK",
  "safety_key": "ctrl+shift+f10"
}
```

### Для Counter-Strike 2
```json
{
  "games": ["cs2.exe"],
  "forbidden_apps": ["Telegram.exe", "Spotify.exe"],
  "cruelty_mode": "REFOCUS",
  "safety_key": "ctrl+alt+p"
}
```

## Требования

- Python 3.8+
- Windows (использует win32api)
- Права администратора
- Зависимости:
  - psutil
  - pywin32
  - keyboard

## Устранение проблем

### "Error registering hotkey"
**Решение:** Запустите скрипт от имени администратора

### "Failed to block input"
**Решение:** Проверьте, что keyboard установлен правильно и у вас права администратора

### Название процесса игры
**Как найти:** Откройте Диспетчер задач → вкладка "Процессы" → найдите игру → имя в столбце "Имя"

## Архитектура

Проект состоит из трех модулей:

### `overseer.py`
Мониторинг активных окон и процессов. Определяет, какое приложение активно.

### `combat.py`
Реализация режимов блокировки (INPUT_BLOCK, BLACK_SCREEN, REFOCUS).

### `main.py`
Главный цикл приложения, связывает Overseer и Combat.

## Безопасность

- Используйте ответственно
- Не блокируйте системные процессы
- Помните safety key для экстренного отключения
- Рекомендуется INPUT_BLOCK режим для начала
