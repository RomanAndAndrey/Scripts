# Dota Coach Overlay

Прозрачный оверлей для Dota 2, отображающий советы при смерти персонажа.

## Возможности

- ✅ **Автоматическое обнаружение смерти** - анализ серого экрана
- ✅ **Случайные советы** - мотивация после неудачи
- ✅ **Прозрачный оверлей** - не мешает игре
- ✅ **Всегда поверх** - отображается над Dota 2
- ✅ **Click-through** - клики проходят через оверлей
- ✅ **Настраиваемые советы** - редактируйте tips.json

## Требования

- Python 3.8+
- Windows (использует win32api)
- Dota 2

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте tips.json с вашими советами

3. Запустите скрипт:
```bash
python main.py
```

## Настройка

### tips.json

Отредактируйте файл `tips.json`, чтобы добавить свои советы:

```json
{
  "tips": [
    "Анализируй ошибки. Что пошло не так?",
    "Проверь карту перед выходом из базы",
    "Купи Observer Ward и поставь его",
    "Общайся с командой через микрофон",
    "Следи за предметами врагов"
  ]
}
```

### Калибровка обнаружения смерти

В файле `main.py` можно настроить параметры обнаружения:

```python
# Координаты для проверки (центр экрана)
x, y = w//2, h//2

# Размер области для анализа
region_size = 100

# Порог яркости для определения "серого экрана"
gray_threshold = 100
```

**Рекомендуется:** Запустите Dota 2, умрите и посмотрите на координаты серого экрана в консоли, затем скорректируйте параметры.

## Использование

1. Запустите `main.py`
2. Запустите Dota 2
3. Играйте как обычно
4. При смерти появится оверлей с советом
5. Для выхода нажмите `Ctrl+C` в консоли

## Архитектура

### main.py
Главный модуль с классом `DotaOverlay`:
- Создает прозрачное окно Tkinter
- Мониторит экран через pyautogui
- Определяет смерть по цвету экрана
- Отображает случайные советы

### tips.json
JSON файл со списком советов для отображения.

## Принцип работы

1. **Захват экрана:** pyautogui делает скриншот каждую секунду
2. **Анализ цвета:** Проверяется яркость пикселей в центре экрана
3. **Обнаружение смерти:** Если экран серый (низкая яркость) → смерть обнаружена
4. **Отображение совета:** Выбирается случайный совет из tips.json
5. **Скрытие:** Когда экран становится цветным → оверлей скрывается

## Оптимизация

### Снижение нагрузки на CPU

1. **Увеличить интервал проверки:**
```python
time.sleep(1)  # Изменить на 2-3 секунды
```

2. **Уменьшить область анализа:**
```python
region_size = 50  # Вместо 100
```

3. **Использовать более быстрый метод захвата:**
```python
# Захватывать только малую область вместо всего экрана
screenshot = pyautogui.screenshot(region=(x, y, 100, 100))
```

## Устранение проблем

### Оверлей не появляется при смерти
**Решение:**
1. Проверьте координаты захвата экрана (должны быть в центре)
2. Настройте `gray_threshold` - попробуйте значения от 50 до 150
3. Убедитесь, что игра в оконном/borderless режиме

### Оверлей не исчезает
**Решение:**
- Перезапустите скрипт
- Проверьте логику `check_death_condition()` - возможно порог слишком высокий

### Высокая нагрузка на процессор
**Решение:**
- Увеличьте `time.sleep()` до 2-3 секунд
- Уменьшите размер захватываемой области

### Советы не отображаются
**Решение:**
- Проверьте формат tips.json (должен быть валидный JSON)
- Убедитесь, что кодировка файла UTF-8
- Проверьте путь к tips.json в коде

- Скрипт анализирует только цвет экрана, не читает игровую память

- Не нарушает правила Valve (не вмешивается в игровой процесс)
