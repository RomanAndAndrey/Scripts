# Script Launcher

Веб-интерфейс на Streamlit для запуска Python скриптов с параметрами и мониторингом выполнения в реальном времени.

## Возможности

- ✅ **Web UI** - удобный интерфейс через браузер
- ✅ **Динамические параметры** - автоматическая генерация полей ввода из конфигурации
- ✅ **Мониторинг в реальном времени** - отображение логов во время выполнения
- ✅ **Управление процессами** - запуск и остановка скриптов
- ✅ **JSON конфигурация** - легко добавлять новые скрипты
- ✅ **Типы параметров** - text, int, float, bool

## Установка

```bash
pip install -r requirements.txt
```

**Зависимости:**
- streamlit

## Использование

### 1. Настройте scripts_config.json

```json
[
  {
    "name": "Тестовый скрипт",
    "path": "test_script.py",
    "description": "Демо-скрипт для проверки",
    "args": [
      {
        "name": "count",
        "label": "Количество итераций",
        "type": "int",
        "default": 10
      },
      {
        "name": "message",
        "label": "Сообщение",
        "type": "text",
        "default": "Hello"
      },
      {
        "name": "verbose",
        "label": "Подробный вывод",
        "type": "bool",
        "default": false
      }
    ]
  }
]
```

### 2. Запустите Streamlit

```bash
streamlit run app.py
```

### 3. Откройте браузер

Приложение автоматически откроется в браузере по адресу `http://localhost:8501`

## Конфигурация

### Структура scripts_config.json

```json
[
  {
    "name": "Название скрипта",
    "path": "path/to/script.py",
    "description": "Описание функциональности",
    "args": [
      {
        "name": "arg_name",          // Имя аргумента (используется в CLI)
        "label": "Отображаемое имя", // Текст в UI
        "type": "text|int|float|bool", // Тип параметра
        "default": "значение"        // Значение по умолчанию
      }
    ]
  }
]
```

### Поддерживаемые типы аргументов:

**text** (по умолчанию):
```json
{
  "name": "filename",
  "label": "Имя файла",
  "type": "text",
  "default": "output.txt"
}
```

**int** (целое число):
```json
{
  "name": "count",
  "label": "Количество",
  "type": "int",
  "default": 100
}
```

**float** (дробное число):
```json
{
  "name": "threshold",
  "label": "Порог",
  "type": "float",
  "default": 0.5
}
```

**bool** (чекбокс):
```json
{
  "name": "debug",
  "label": "Режим отладки",
  "type": "bool",
  "default": false
}
```

## Функции

### `load_config() -> List[Dict[str, Any]]`
Загружает конфигурацию скриптов из JSON.

### `run_script(script_path: str, args_list: List[str]) -> Optional[subprocess.Popen]`
Запускает скрипт в подпроцессе с аргументами.

### `enqueue_output(process: subprocess.Popen, log_queue: queue.Queue) -> None`
Читает вывод процесса и помещает в очередь для отображения.

## Особенности реализации

### Состояние сессии
Streamlit использует `st.session_state` для хранения:
- `running_process` - текущий запущенный процесс
- `log_queue` - очередь логов
- `logs` - накопленные логи
- `script_finished` - флаг завершения

### Автообновление
При запущенном процессе страница автоматически обновляется каждые 0.5 секунды для отображения новых логов.

### Потоки
Вывод процесса читается в отдельном потоке (daemon), чтобы не блокировать UI.

## Ограничения

- **Один процесс одновременно** - нельзя запустить несколько скриптов параллельно
- **Без хранения истории** - логи сбрасываются при перезапуске
- **Нет аутентификации** - доступ открыт для всех в локальной сети

## Устранение Проблем

### "Файл конфигурации не найден"
**Решение:** Убедитесь, что `scripts_config.json` находится в той же папке, что и `app.py`

### "Скрипт не найден"
**Решение:** Проверьте пути в конфигурации. Пути должны быть относительно директории ScriptLauncher

### Логи не обновляются
**Решение:** Убедитесь, что ваш скрипт выводит текст с помощью `print()` и использует `flush=True` если нужно

### Streamlit перезагружается слишком часто
**Решение:** Увеличьте значение `time.sleep(0.5)` до 1-2 секунд в конце app.py

## Безопасность
