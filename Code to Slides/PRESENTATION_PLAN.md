# Структура презентации защиты проекта "File Organizer"

## 1. Титульный слайд
- **Название проекта**: File Organizer
- **Автор**: Бадалин А.Д.
- **Группа**: ИС 3.1

## 2. Цель
- Автоматизация процесса сортировки файлов в папке "Загрузки".
- Повышение эффективности работы с учебными материалами.
- Поддержание порядка в файловой системе.

## 3. Задачи
- Мониторинг новых файлов в реальном времени (Watchdog).
- Анализ содержимого PDF и DOCX документов на наличие ключевых слов.
- Автоматическое определение категории файла по расширению.
- Перемещение файлов в соответствующие тематические папки (Учеба, Изображения, Архивы и др.).

## 4. Стек технологий
- **Python 3.14**: Язык программирования.
- **watchdog**: Отслеживание изменений файловой системы.
- **pypdf**: Извлечение текста из PDF.
- **python-docx**: Чтение документов Word.
- **shutil / os**: Базовые операции с файлами.

### Анализ PDF документов
```python
def check_pdf_content(file_path):
    """Сканирует PDF на наличие ключевых слов."""
    try:
        reader = PdfReader(file_path)
        for page in reader.pages[:5]:
            if any(k in page.extract_text() for k in KEYWORDS):
                return True
    except Exception:
        pass
    return False
```

### Обработчик событий (Watchdog)
```python
class OrganizerHandler(FileSystemEventHandler):
    def on_created(self, event):
        if not event.is_directory:
            self.process_file(event.src_path)
```
