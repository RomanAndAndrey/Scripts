# Code to Slides

Генератор PowerPoint презентаций из Markdown файлов. Автоматически создает профессиональные слайды на основе структурированного плана.

## Возможности

- ✅ **Парсинг Markdown** - читает PRESENTATION_PLAN.md
- ✅ **Автоматическое создание слайдов:**
  - Титульный слайд
  - Слайды с буллетами (цели, задачи, стек)
  - Слайды с кодом (моноширинный шрифт)
  - Слайды с изображениями (архитектура)
- ✅ **Поддержка изображений** - автоматический поиск и вставка
- ✅ **Кастомное форматирование** - Consolas для кода, Calibri для текста

### Презентация с кодом

```markdown
## Алгоритмы

### Быстрая сортировка

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)
```
```

## Настройка

### Шрифты
- Код: Consolas, 11pt
- Текст: Calibri, стандартный размер
- Заголовки: Calibri, 24pt (титульный)

### Макеты
- Титульный: Layout 0 (Title Slide)
- С буллетами: Layout 1 (Title and Content)
- Только заголовок: Layout 5 (Title Only) - для кода и изображений

## Устранение проблем

### "Plan file not found!"
**Решение:** Создайте файл PRESENTATION_PLAN.md в той же папке

### Изображение не найдено
**Решение:** Убедитесь, что файл изображения находится в корне проекта или в папке скрипта

### Код не влезает на слайд
**Решение:** Сократите код или разбейте на несколько слайдов

## Архитектура

### Состояния парсера:
- `NORMAL` - обычный режим
- `TITLE` - обработка титульного слайда
- `CONTENT` - обработка буллетов
- `ARCH` - обработка архитектурных диаграмм
- `CODE_SECTION` - ожидание блоков кода
- `IN_CODE_BLOCK` - внутри блока кода

### Функции:
- `main()` - главная функция генерации
- `process_header()` - обработка заголовков
- `add_code_to_slide()` - добавление кода
- `process_content()` - обработка контента
- `add_architecture_image()` - вставка изображений

## Ограничения

- Поддержка только заголовков ## и ###
- Одно изображение на слайд (db_schema.png)
- Фиксированные размеры текстовых блоков
- Кириллица может некорректно отображаться в некоторых версиях PowerPoint (используйте UTF-8)
