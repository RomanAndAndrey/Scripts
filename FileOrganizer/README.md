# File Organizer

Автоматический организатор файлов для папки Загрузки с анализом содержимого PDF/DOCX и сортировкой по категориям.

## Возможности

- ✅ Автоматическая сортировка файлов по категориям на основе расширений
- ✅ Интеллектуальный анализ содержимого PDF и DOCX для категории "Учеба"
- ✅ Мониторинг в реальном времени через watchdog
- ✅ Обработка дубликатов файлов (добавление счетчика)
- ✅ Логирование всех операций в файл organizer.log
- ✅ Кроссплатформенность (Windows, Linux, macOS)

## Категории

- **Изображения:** .jpg, .png, .gif, .svg, .webp и др.
- **Инсталляторы:** .exe, .msi, .bat, .cmd
- **Архивы:** .zip, .rar, .7z, .tar, .gz, .iso
- **Видео:** .mp4, .mkv, .avi, .mov и др.
- **Презентации:** .pptx, .ppt, .odp
- **Торрент:** .torrent
- **Учеба:** PDF/DOCX с ключевыми словами (лабораторная, курсовая, лекция и др.)

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что в вашей системе есть папка Downloads (создается автоматически)

## Использование

Запустите скрипт:

```bash
python organizer.py
```

Скрипт будет:
1. Сканировать существующие файлы в папке Downloads
2. Начнет мониторинг новых файлов в реальном времени
3. Автоматически сортировать файлы по подпапкам

**Остановка:** Нажмите `Ctrl+C`

## Логирование

Все операции логируются в файл `organizer.log`:
- Успешные перемещения файлов
- Найденные ключевые слова в документах
- Ошибки чтения файлов
- Предупреждения (например, timeout при ожидании готовности файла)

## Настройка

Вы можете настроить:
- **Категории:** Редактируйте словарь `CATEGORIES` в `organizer.py`
- **Ключевые слова:** Редактируйте список `STUDY_KEYWORDS`
- **Отслеживаемые папки:** Редактируйте список `WATCH_DIRS`

## Особенности реализации

- **Безопасная проверка готовности файлов:** Функция `wait_for_file_ready()` ждет, пока файл перестанет изменяться
- **Pathlib для путей:** Используется `pathlib.Path` для кроссплатформенности
- **Типизация:** Добавлены type hints для улучшения читаемости
- **Логирование вместо print:** Структурированное логирование с ротацией файлов

## Требования

- Python 3.8+
- watchdog
- pypdf
- python-docx

## Примечания

- Временные файлы (.tmp, .crdownload, .part) игнорируются
- Скрытые файлы (начинающиеся с точки) игнорируются
- При дублировании имен добавляется счетчик (например, file_1.pdf)
